GimmeComments

Comments as a service. One script tag, and any website gets a working comment box.

This page is a plain static file hosted on GitHub Pages. It has no backend of its own. Everything below the line is loaded from a Spring Boot service running somewhere else entirely — which is the whole point.

How a site embeds it

<div id="gimme-comments-root"
     data-gimme_comments_website_id="your-website-id"></div>

<script src="https://gimme-comments-server-p7av.onrender.com/initialize-gimme-comments.js"></script>

The loader asks the server which bundle files are current, then injects them. It works out its own origin from the script tag it was served by, so the same snippet works against any deployment.

Here it is, running

First load may take up to a minute. The API runs on a free instance that sleeps after inactivity, so the first request has to wake it. Reading comments is public; posting one needs an account.
